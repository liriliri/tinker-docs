# tinker-screenshot-mockup

截图美化插件，为截图添加设备边框和背景，快速生成商店或营销展示图。

![截图](/screenshot_mockup.png)

## 功能特性

- **设备边框** — 将截图放入手机、平板或电脑边框（也可隐藏边框）
- **多设备场景** — 在同一画布上添加、复制和删除多个设备
- **画布预设** — 支持 App Store、Play Store、Instagram、Open Graph 及自定义尺寸
- **背景选项** — 渐变预设、纯色、自定义图片或透明背景
- **阴影与变换** — 拖拽、缩放、旋转设备，并支持开关投影
- **导出** — 将合成后的展示图导出为图片

## 使用方法

1. 在工具栏选择画布预设或设置自定义尺寸
2. 点击设备添加截图（或更换已有截图）
3. 选择设备类型（手机 / 平板 / 电脑），按需开关设备边框
4. 用渐变、纯色或图片设置背景样式
5. 在画布上拖拽、缩放或旋转设备；用 + 按钮添加更多设备
6. 点击导出保存展示图
