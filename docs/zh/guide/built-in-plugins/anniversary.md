# tinker-anniversary

记录每年纪念日的插件，支持日历展示和倒数天数。

![截图](/anniversary.png)

## 功能特性

- **日历视图** — 月历视图展示所有纪念日和节日事件
- **公历和农历** — 支持公历（阳历）和农历日期
- **倒数侧边栏** — 按剩余天数排序展示即将到来的纪念日和节日
- **节日显示** — 可切换显示/隐藏公共节日
- **起始年份** — 可选设置起始年份，查看纪念日已过去的天数
- **农历日期标注** — 中文环境下每个日历格显示对应的农历日期

## 使用方法

1. 在日历上双击任意日期即可添加新纪念日
2. 输入名称，选择公历或农历，然后设置日期
3. 可选设置起始年份以追踪已过去的天数
4. 在侧边栏中查看按剩余天数排序的纪念日和节日
5. 点击侧边栏中的项目可在日历中导航到对应日期
6. 右键点击侧边栏中的纪念日可编辑或删除
7. 使用工具栏中的复选框可显示或隐藏节日
