# tinker-image-splitter

图片分割插件，支持多种网格布局将图片切分为多块。

![截图](/image_splitter.png)

## 功能特性

- **网格预设** — 9 种预设布局一键选择（2x1、1x2、2x2、3x3、3x1、1x3、2x3、3x2、4x4）
- **自定义网格** — 手动设置行数和列数（各 1–16），自由配置任意网格
- **可调分割线** — 拖拽网格线调整各单元格比例
- **裁剪区域** — 定义裁剪区域，仅分割图片的指定部分
- **单元格预览** — 导出前预览每个分割后的单元格
- **批量导出** — 将所有单元格以 PNG 格式按编号命名导出到指定目录

## 使用方法

1. 点击**打开图片**或将图片拖放到画布上
2. 选择网格预设或手动调整行数和列数
3. 如需调整比例，拖拽网格分割线
4. 拖拽裁剪区域控制点聚焦到特定区域
5. 在侧边栏预览分割后的单元格效果
6. 点击**保存分割图片**并选择输出目录导出所有单元格
