# tinker-sftp

SFTP 客户端插件，通过 SSH 浏览和传输远程文件。

![截图](/sftp.png)

## 功能特性

- **会话管理** — 将会话分文件夹整理，保存凭据以便快速访问
- **密码和密钥认证** — 支持密码和 SSH 私钥两种认证方式
- **多标签浏览** — 在多个标签页中打开连接并可自由切换
- **文件浏览器** — 以列表或网格视图浏览远程目录，支持按名称/大小/修改时间排序
- **上传和下载** — 传输文件和目录，带进度追踪
- **远程文件操作** — 在远程服务器上新建文件夹、重命名、删除文件/目录
- **路径导航** — 前进、后退、向上一级或直接输入路径；按名称筛选文件
- **显示隐藏文件** — 切换隐藏文件的可见性
- **传输面板** — 查看进行中和已完成的传输任务及进度条

## 使用方法

1. 点击**新建文件夹**创建会话分组，再点击**新建会话**添加连接
2. 输入主机、端口、用户名，选择密码或私钥认证方式
3. 双击会话进行连接，即可看到远程目录列表
4. 点击目录进行导航，或使用后退/前进/上级按钮
5. 选中文件后点击**下载**保存到本地，或点击**上传**发送本地文件
6. 右键点击文件可重命名或删除
7. 打开传输面板查看所有文件传输的进度
