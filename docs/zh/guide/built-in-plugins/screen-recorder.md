# tinker-screen-recorder

[TINKER](https://github.com/liriliri/tinker) 的录屏插件，支持将桌面屏幕或应用窗口录制为视频文件。

![Screenshot](/screen_recorder.png)

## 功能特性

- **屏幕与窗口捕获** — 可选择全屏或单个窗口作为录制源
- **录制源选择** — 浏览可用录制源，并显示实时缩略图
- **刷新录制源** — 随时重新加载屏幕和窗口列表
- **实时预览** — 录制过程中实时查看捕获画面
- **录制计时** — 实时显示当前录制时长
- **回放预览** — 保存前可预览录制的视频
- **保存为 WebM** — 将录制导出为 WebM 视频文件

## 使用方法

1. 在工具栏选择**屏幕**或**窗口**以确定捕获类型
2. 点击缩略图选择要录制的源（列表过期时可点击**刷新**）
3. 在 macOS 上如有提示，请在系统设置中授予屏幕录制权限
4. 点击**开始**开始录制
5. 点击**结束**停止录制
6. 使用内置播放器预览录制内容
7. 点击**保存**导出为 WebM 文件，或点击**取消**丢弃录制
