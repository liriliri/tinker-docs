# tinker-hotkeys

[TINKER](https://github.com/liriliri/tinker) 全局快捷键管理插件，可将热键绑定到自定义操作。

![截图](/hotkeys.png)

## 功能

- **全局快捷键** — 注册系统级快捷键，即使 TINKER 在后台也能响应
- **多种操作类型** — 可执行 Shell 命令、打开应用、打开目录、访问 URL，或启动 TINKER 插件
- **快捷键录制** — 点击快捷键输入框并按下组合键即可录制
- **启用 / 禁用** — 可单独开关操作，无需删除
- **筛选与搜索** — 按操作类型（命令、插件、应用、目录、URL）筛选，并按名称、快捷键或目标搜索
- **冲突检测** — 快捷键因冲突或权限不足注册失败时显示警告
- **快速运行** — 可直接从列表执行操作，无需按下快捷键

## 使用方法

1. 点击 **+** 按钮添加命令，或通过下拉菜单添加插件、应用、目录或 URL
2. 输入名称，点击快捷键输入框并按下要绑定的组合键
3. 填写目标（命令、应用、目录、URL 或插件），然后点击**保存**
4. 在系统任意位置按下已注册的快捷键即可触发操作
5. 使用每行的开关按钮启用或禁用快捷键；按需点击**运行**、**编辑**或**删除**
6. 使用工具栏标签和搜索框筛选操作列表

> **注意：** 若快捷键无法注册（冲突或权限不足），操作旁会显示警告图标。
