# tinker-video-cropper

视频裁剪插件，支持交互式区域选择，并通过 FFmpeg 导出。

![截图](/video_cropper.png)

## 功能特性

- **交互式裁剪** — 在播放中的视频上拖拽、调整裁剪区域
- **宽高比预设** — 自由、原始比例、1:1、4:3、3:2、16:9
- **自定义裁剪尺寸** — 以像素为单位设置精确的宽和高
- **拖放打开** — 将视频文件拖到窗口即可打开
- **格式支持** — 支持 MP4、WebM、MOV、MKV 等格式
- **FFmpeg 导出** — 通过 FFmpeg 裁剪并保存，显示进度
- **覆盖或另存** — 可另存为新文件，也可覆盖原文件

## 使用方法

1. 点击空白区域（或工具栏打开按钮）加载视频，或直接拖放视频文件
2. 在视频上拖动裁剪框，选择要保留的区域
3. 可选选择宽高比预设，或在工具栏设置精确裁剪尺寸
4. 点击**裁剪**并选择保存位置
5. 完成后，裁剪结果会在编辑器中打开，便于继续调整
