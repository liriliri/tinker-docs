# tinker-pie-menu

[TINKER](https://github.com/liriliri/tinker) 径向悬浮饼菜单插件，可通过常驻悬浮球或中键唤起快速执行操作。

![截图](/pie_menu.png)

## 功能

- **径向饼菜单** — 将操作布置在 8 扇区圆形菜单中，便于快速访问
- **常驻悬浮球** — 在屏幕上保持悬浮球，点击即可展开饼菜单
- **中键唤起** — 长按鼠标中键，在光标位置显示饼菜单
- **双环** — 可选启用外圈 16 个扇区（每个内圈扇区对应两个）
- **多种操作类型** — 可执行 Shell 命令、打开应用、打开目录、访问 URL，或启动 TINKER 插件
- **启用 / 禁用** — 可单独开关扇区，无需清除配置
- **快速运行** — 可在配置面板中立即执行当前选中扇区的操作

## 使用方法

1. 在饼菜单预览中点击扇区选中，然后选择操作类型（命令、应用、目录、URL 或插件）
2. 在右侧面板配置操作名称和目标
3. 开启**双环**可为外圈增加更多扇区
4. 选择**常驻浮窗**以保持悬浮球显示，或选择**中键唤起**以通过长按鼠标中键打开菜单
5. 常驻模式下，点击悬浮球展开菜单，再点击扇区执行操作
6. 中键模式下，长按鼠标中键在光标处显示菜单并选择扇区
