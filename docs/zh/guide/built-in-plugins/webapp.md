# tinker-webapp

将任意网站添加为 [TINKER](https://github.com/liriliri/tinker) 插件的网页应用管理器。

![截图](/webapp.png)

## 功能特性

- **网站转插件** — 将任意 http(s) 网址保存为可像原生工具一样打开的 Tinker 插件
- **应用列表** — 以卡片网格浏览所有网页应用，显示名称、网址、描述和图标
- **自动获取图标** — 输入网址后自动抓取网站 favicon
- **自定义图标** — 可选择本地图片（png、jpg、ico、webp、svg），或移除后重新抓取
- **插件 ID** — 根据名称自动建议 slug，前缀为 `tinker-web-`
- **分类** — 可指定开发、文件、多媒体、效率、系统或娱乐
- **编辑与删除** — 可更新名称、网址、分类、描述和图标，删除前需确认
- **作为插件打开** — 点击卡片即可启动已安装的网页应用插件

## 使用方法

1. 点击工具栏上的 **+** 按钮添加网页应用
2. 输入**名称**（插件 ID 会自动建议）和网站**网址**
3. 可选设置**分类**、**描述**和图标（自动抓取或手动选择）
4. 点击**保存**，网站将安装为 Tinker 插件
5. 点击列表中的卡片打开该网页应用
6. 鼠标悬停在卡片上，使用**编辑**或**删除**进行管理
