# tinker-ai-image

AI 生图插件，使用已配置的 AI 生图接口生成和编辑图片。

![截图](/ai_image.png)

## 功能特性

- **多提供商支持** — 使用在 设置 → AI → 生图 中配置的提供商生成图片
- **提示词工具** — 支持复制、粘贴、清除，以及 AI 优化提示词
- **图片编辑** — 设置主图以编辑现有图片，而非从零生成
- **参考图** — 最多添加 4 张参考图，用于风格或内容指引
- **尺寸与数量** — 自定义宽度、高度和批量数量（1–4）
- **任务队列** — 可排队多个生成任务，并支持停止正在运行的任务
- **图库** — 预览结果、另存为、在文件夹中显示、删除或清空全部
- **输出目录** — 选择生成图片的保存位置，或使用默认临时目录

## 使用方法

1. 在 设置 → AI → 生图 中至少配置一个生图提供商
2. 在侧边栏选择提供商和模型
3. 输入描述想要生成图片的提示词
4. 可选：设置主图进行编辑，或添加参考图
5. 按需调整宽度、高度和数量
6. 点击生成，结果会出现在图库中
7. 可另存为、在文件夹中打开，或将结果设为主图继续编辑
