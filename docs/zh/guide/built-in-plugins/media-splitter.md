# tinker-media-splitter

一款用于 [TINKER](https://github.com/liriliri/tinker) 的音视频分割插件，将音视频切分成多段，并通过 FFmpeg 无损导出。

![截图](/media_splitter.png)

## 功能特性

- **音视频支持** — 支持打开 MP4、MKV、MOV、MP3、WAV 等，可通过对话框或拖放导入
- **设置起止点** — 在播放头位置标记片段起点和终点（快捷键 **I** / **O**）
- **时间轴编辑** — 可在时间轴上拖动定位；音频文件显示波形预览
- **均分切割** — 将整段媒体均分成 2–100 段，并显示每段时长与大小预估
- **片段工具** — 添加、在光标处分割、删除或清空片段；查看每个片段的时长与预估大小
- **无损导出** — 基于 FFmpeg 流拷贝，可选关键帧对齐切割
- **自定义输出目录** — 保存到源文件同目录或指定文件夹
- **进度与取消** — 显示导出进度，可随时取消

## 使用方法

1. 点击**打开媒体**，或拖放音视频文件
2. 播放并定位到切割点，按 **I** / **O**（或使用播放栏按钮）设置起点和终点
3. 可选使用**均分成多段**，或在侧栏中添加 / 分割 / 删除片段
4. 按需选择输出目录；可开启**关键帧切割**以加快关键帧对齐定位
5. 点击**导出**，无损切出所有完整片段
