# tinker-reader

PDF 阅读器插件，支持书库管理和本地书籍阅读。

![截图](/reader.png)

## 功能特性

- **书库管理** — 导入单本 PDF 或扫描文件夹来构建书库
- **画廊视图** — 浏览书籍，自动生成封面缩略图，按最近打开时间排序
- **搜索** — 按书名或文件路径筛选书籍
- **PDF 阅读** — 阅读 PDF，支持翻页、缩放和自适应宽度
- **阅读进度** — 记住上次阅读页码并显示每本书的阅读百分比
- **侧边栏** — 切换缩略图预览和文档大纲以便快速导航
- **阅读追踪** — 记录每本书的最后打开时间和阅读进度

## 使用方法

1. 点击**导入**添加单本 PDF，或点击**扫描文件夹**批量发现书籍
2. 点击书籍卡片即可打开阅读器
3. 使用**上一页** / **下一页**按钮或键盘翻页
4. 使用**放大** / **缩小** / **重置缩放**调整视图
5. 打开侧边栏查看页面缩略图或文档大纲进行导航
6. 在书库中右键点击书籍可移除或在 Finder 中显示
