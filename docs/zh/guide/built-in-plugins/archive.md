# tinker-archive

压缩包管理插件，用于查看、解压和创建基于 ZIP 的压缩包文件。

![截图](/archive.png)

## 功能特性

- **打开压缩包** — 通过文件对话框或拖拽打开基于 ZIP 的文件（zip、apk、jar、docx、epub 等）
- **创建压缩包** — 创建空的 ZIP 文件并开始添加内容
- **浏览内容** — 通过前进/后退/上级、路径面包屑和路径输入在文件夹间导航
- **添加与整理** — 添加本地文件或文件夹，在压缩包内创建目录
- **解压** — 将选中条目或整个压缩包解压到本地目录
- **删除** — 从压缩包中删除文件和文件夹（更改立即保存）
- **列表与网格视图** — 在列表和网格布局间切换；按名称、大小或修改时间排序
- **筛选** — 按名称快速筛选条目

## 使用方法

1. 点击工具栏中的**打开压缩包**，或将基于 ZIP 的文件拖拽到窗口中
2. 浏览压缩包内容；双击文件夹进入
3. 使用**添加文件**或**新建文件夹**修改压缩包
4. 选中条目后，通过右键菜单**解压**或**删除**
5. 如需全部解压，在空白处右键选择**全部解压**

### 创建新压缩包

1. 点击工具栏中的**新建压缩包**
2. 选择 `.zip` 文件的保存位置
3. 按需添加文件和文件夹
