# tinker-habit

[TINKER](https://github.com/liriliri/tinker) 的习惯打卡插件，支持按周几、每周次数或每月次数设置，并在月视图中查看打卡记录。

![截图](/habit.png)

## 功能特性

- **灵活打卡规则** — 可按指定周几、每周次数或每月次数设置习惯
- **月历视图** — 在月视图中按习惯颜色展示打卡记录
- **当日侧栏** — 选择日期后，在侧栏切换当日应打卡习惯的完成状态
- **习惯列表** — 管理全部习惯，查看完成率、连续天数与周期进度
- **自定义颜色** — 为每个习惯指定颜色，用于日历与侧栏展示
- **结束或删除** — 结束习惯并保留历史记录，或删除习惯及其全部打卡
- **工具栏导航** — 切换月份、回到今天，并显示或隐藏侧栏

## 使用方法

1. 点击工具栏的 **+** 按钮添加新习惯
2. 输入名称，选择颜色，并设置打卡规则（按周几、每周次数或每月次数）
3. 在日历上点击日期进行选择；当日侧栏会列出该日应打卡的习惯
4. 在当日侧栏中点击习惯即可打卡或取消打卡
5. 切换到习惯标签页，查看每个习惯的完成率、连续天数与周期进度
6. 在习惯列表中编辑、结束或删除习惯（也可通过右键菜单操作）
7. 使用工具栏箭头切换月份，点击**今天**回到当前日期，并用面板按钮显示或隐藏侧栏
