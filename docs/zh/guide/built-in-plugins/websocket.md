# tinker-websocket

WebSocket 调试插件，用于连接 WebSocket 服务器、发送消息和查看通信内容。

![截图](/websocket.png)

## 功能特性

- **多连接** — 同时连接多个 `ws://` 或 `wss://` 端点
- **发送文本与二进制** — 发送文本消息，或从本地文件发送二进制数据
- **消息历史** — 查看出站、入站和系统消息，含时间戳与大小
- **筛选与搜索** — 按方向筛选（全部 / 已发送 / 已接收），并搜索消息内容
- **消息详情** — 以文本或十六进制视图检查消息
- **URL 历史** — 记住最近使用的 WebSocket URL，便于快速重连
- **连接管理** — 按连接断开、删除或清空消息历史

## 使用方法

1. 点击**新建连接**并输入 WebSocket URL（例如 `wss://ws.postman-echo.com/raw`）
2. 连接成功后，在侧边栏中选中该连接
3. 在编辑区输入消息，按 **Enter** 或点击**发送**
4. 可选点击文件按钮发送二进制数据
5. 点击消息列表中的条目查看内容、大小和时间戳
