# tinker-resume

简历制作插件，支持实时预览、模板选择和 PDF 导出。

![截图](/resume.png)

## 功能特性

- **模块化章节** — 编辑基本信息、专业技能、工作经验、项目经历、教育经历、自我评价和荣誉证书；可按需添加或移除可选模块
- **实时预览** — 修改内容后预览即时更新
- **模板** — 在经典单栏和左侧边栏两种布局间切换
- **主题色** — 在工具栏自定义强调色
- **条目显隐** — 可隐藏或显示单条工作经验、项目、教育或证书，无需删除
- **章节排序** — 拖拽侧栏章节调整简历中的顺序
- **照片支持** — 从本地选择个人照片
- **自动保存** — 简历内容、模板和主题色会本地持久化
- **PDF 导出** — 将当前预览导出为 PDF 文件
- **AI 助手** — 可选的聊天助手，帮助撰写、改写或翻译简历（需可用 AI）

## 使用方法

1. 从左侧边栏打开章节（如基本信息）并填写内容
2. 按需添加工作经验、项目经历、教育经历或荣誉证书条目
3. 使用侧栏底部的**添加模块**恢复已移除的章节
4. 在工具栏切换**经典单栏**和**左侧边栏**模板
5. 可选调整**主题色**
6. 点击**导出 PDF**将简历保存为 PDF
