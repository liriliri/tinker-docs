# tinker-image-effect

图片效果插件，为图片添加素描、像素画、ASCII 等艺术效果。

![截图](/image_effect.png)

## 功能特性

- **素描效果** — 将图片转为铅笔素描，可调整粗细、亮度、细节和加深
- **像素画效果** — 将图片转为像素风，可配置像素大小、黑色描边，以及 12 种调色板（PICO-8、Gameboy、复古 NES、赛博朋克等）
- **ASCII 效果** — 将图片渲染为 ASCII 艺术字，可调整字符大小、对比度、反色及字符集（简洁、精细、色块）
- **实时预览** — 调整参数时画布实时更新预览
- **拖放** — 支持拖放或文件对话框打开图片（PNG、JPG、WebP、GIF、BMP）
- **导出** — 将结果保存为 PNG、JPG 或 WebP；可选择覆盖原图
- **EXIF 保留** — 保存 JPEG 时保留原始 EXIF 元数据

## 使用方法

1. 点击**打开图片**或将图片拖放到画布上
2. 在侧边栏选择效果：**素描**、**像素画**或 **ASCII**
3. 使用滑块和选项调整效果参数
4. 在画布上实时预览结果
5. 点击**保存图片**导出为 PNG、JPG 或 WebP
6. 启用**覆盖原图**直接保存到原始文件
