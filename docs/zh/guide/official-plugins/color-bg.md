# tinker-color-bg

基于 [color4bg.js](https://github.com/winterx/color4bg.js) 的 [TINKER](https://github.com/liriliri/tinker) 炫彩抽象背景生成插件。

![Screenshot](https://raw.githubusercontent.com/liriliri/tinker-plugins/master/packages/tinker-color-bg/screenshot.png)

## 功能特性

- **13 种 WebGL 风格** — aesthetic fluid、ambient light、wavy waves 等
- **实时预览** — 全屏动态渲染
- **调色板** — 支持预设调色板与单色自定义
- **风格选项** — 可调整 seed、动画、noise、scale、speed 等
- **PNG 导出** — 支持自定义宽高导出

## 安装

下载并安装 [TINKER](https://tinker.liriliri.io/)，然后运行：

```bash
npm i -g tinker-color-bg
```

## 使用方法

1. 点击左侧风格按钮选择背景风格
2. 在右侧选择调色板或编辑单个颜色
3. 按需调整 seed、动画及其他风格相关选项
4. 设置导出尺寸，点击「Export PNG」保存图片
