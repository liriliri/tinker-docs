# tinker-screen-tester

屏幕测试插件，提供全屏纯色与图案，用于检测坏点、漏光与色阶问题。

![截图](https://raw.githubusercontent.com/liriliri/tinker-plugins/master/packages/tinker-screen-tester/screenshot.png)

## 功能特性

- **8 种测试图案** 覆盖白 / RGB / 黑、漏光、灰阶与棋盘格
- **全屏模式** 便于准确检查坏点与漏光
- **实时预览** 开始前循环展示全部图案
- **简单操作** — ← → 切换，点击 / 右键，Esc 退出，H 显示提示

## 安装

下载安装 [TINKER](https://tinker.liriliri.io/)，然后运行：

```bash
npm i -g tinker-screen-tester
```

## 使用方法

1. 打开插件，在预览区查看可用图案
2. 点击 **Start Test** 进入全屏
3. 使用 ← / →（或点击 / 右键）切换图案
4. 按 **H** 显示当前图案名称，按 **Esc** 退出全屏
