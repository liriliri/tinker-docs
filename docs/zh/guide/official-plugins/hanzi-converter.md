# tinker-hanzi-converter

[TINKER](https://github.com/liriliri/tinker) 的汉字工具插件，支持拼音转换、人民币大写和简繁转换。

![截图](https://raw.githubusercontent.com/liriliri/tinker-plugins/master/packages/tinker-hanzi-converter/screenshot.png)

## 功能特性

- **拼音转换**，支持声调符号、数字声调和无声调
- **人民币大写**，将数字转换为中文财务大写
- **简繁转换**，在简体与繁体之间转换
- **点击复制**结果到剪贴板

## 安装

直接在[浏览器](https://tinker.liriliri.io/plugins/hanzi-converter)中体验，或通过 [TINKER](https://tinker.liriliri.io/) 安装：

```bash
npm i -g tinker-hanzi-converter
```

## 使用方法

1. 选择工具标签（拼音、人民币大写或简繁转换）
2. 在输入区输入或粘贴文本
3. 在下方查看转换结果
4. 点击复制按钮将结果复制到剪贴板
