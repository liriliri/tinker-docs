# tinker-search-all

统一搜索插件，可在同一处搜索文件、应用和插件。

![截图](https://raw.githubusercontent.com/liriliri/tinker-plugins/master/packages/tinker-search-all/screenshot.png)

## 功能特性

- **统一搜索** — 在同一处搜索文件、应用和插件
- **分类标签** — 按全部 / 应用 / 插件 / 文件筛选
- **最近项目** — 快速再次打开最近结果
- **键盘导航** — 使用 ↑↓ 选择，Enter 打开
- **全局快捷键** — 用快捷键呼出或隐藏窗口
- **打开后关闭** — 可选在打开结果后自动关闭窗口

## 安装

下载并安装 [TINKER](https://tinker.liriliri.io/)，然后运行：

```bash
npm i -g tinker-search-all
```

## 使用方法

1. 输入关键词搜索文件、应用和插件
2. 使用分类标签缩小结果范围
3. 按 ↑↓ 选择项目，按 Enter 打开
4. 按 Esc 清空查询，再按一次关闭窗口
5. 从状态栏打开设置，配置呼出快捷键和打开后关闭行为

> 若希望窗口关闭后全局快捷键仍然可用，请右键点击插件并启用**后台运行**。
