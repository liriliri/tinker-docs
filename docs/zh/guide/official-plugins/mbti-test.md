# tinker-mbti-test

[TINKER](https://github.com/liriliri/tinker) 的 MBTI 人格测试插件，包含 70 道题目，涵盖四个维度和完整的 16 种人格类型。

![截图](https://raw.githubusercontent.com/liriliri/tinker-plugins/master/packages/tinker-mbti-test/screenshot.png)

## 功能特性

- **70 道题目**覆盖 E/I、S/N、T/F、J/P 四个维度
- **16 种人格类型**提供头像图片、描述、优点、缺点及职业建议
- **维度得分**可视化柱状图展示各维度得分
- **进度条**显示测试进度

## 安装

直接在[浏览器](https://tinker.liriliri.io/plugins/mbti-test)中体验，或通过 [TINKER](https://tinker.liriliri.io/) 安装：

```bash
npm i -g tinker-mbti-test
```

## 使用方法

1. 在介绍页面点击 **Start Test**
2. 选择选项 A 或 B 回答 70 道题目
3. 查看 MBTI 人格类型结果及详细分析
4. 点击 **Restart** 按钮重新测试
