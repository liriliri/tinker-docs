# tinker-bongo-cat

[TINKER](https://github.com/liriliri/tinker) 的 Bongo Cat 桌宠插件。猫咪会随着键盘敲击打鼓，并跟随鼠标指针移动。

![截图](https://raw.githubusercontent.com/liriliri/tinker-plugins/master/packages/tinker-bongo-cat/screenshot.png)

## 功能特性

- **键盘打鼓** — 左手与按键高亮，支持 WASD、QER、Space 和 1–7
- **鼠标跟随** — 右臂与鼠标光标随指针在屏幕上移动
- **按键叠加** — 鼠标左键 / 右键 / 侧键点击会在鼠标上亮起
- **随机表情** — 点击猫头可触发短暂表情
- **悬浮窗口** — 弹出置顶桌宠；可拖拽移动；支持大小滑块；重新打开后自动恢复

## 安装

下载安装 [TINKER](https://tinker.liriliri.io/)，然后运行：

```bash
npm i -g tinker-bongo-cat
```

## 使用方法

1. 打开插件，敲击键盘或移动鼠标 — 猫咪会在主窗口中做出反应
2. 拖动 **Size** 滑块调整场景大小
3. 点击 **Pop out** 弹出置顶悬浮窗口（可拖拽移动）
4. 点击猫头可切换随机表情
5. 悬浮状态下关闭并重新打开插件 — 窗口会自动恢复
