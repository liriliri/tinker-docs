# tinker-radio

[TINKER](https://github.com/liriliri/tinker) 的网络电台插件，可搜索并收听电台。电台绘制在夜景地球上。

![截图](https://raw.githubusercontent.com/liriliri/tinker-plugins/master/packages/tinker-radio/screenshot.png)

## 功能特性

- **夜景地球**展示电台，基于 WebGL——拖动旋转、滚轮缩放、点击圆点播放
- **语言和类型筛选**，下次打开插件时会记住
- **搜索**，可按电台名、地点或语言查找
- **收藏电台**
- **播放控制**，支持上一首、下一首、随机、音量和静音
- **电平表**，播放时显示

## 安装

直接在[浏览器](https://tinker.liriliri.io/plugins/radio)中体验，或通过 [TINKER](https://tinker.liriliri.io/) 安装：

```bash
npm i -g tinker-radio
```

## 使用方法

1. 按播放随机收听一个电台，或点击地球上的圆点
2. 按语言或类型筛选，或从右上角搜索
3. 用爱心收藏电台，并从收藏列表再次打开
4. 按空格播放或暂停，用方向键切换上一首或下一首

## 数据来源

电台数据来自 [Radio Browser](https://www.radio-browser.info/)。
