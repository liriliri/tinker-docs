# tinker-gold-price

黄金价格插件，展示上海黄金交易所 Au9999 行情与分时图。

![截图](https://raw.githubusercontent.com/liriliri/tinker-plugins/master/packages/tinker-gold-price/screenshot.png)

## 功能特性

- **Au9999 行情** — 最新价、涨跌幅与 OHLC
- **分时图** — 展示当前交易时段走势
- **自动刷新** — 每 60 秒自动更新，并支持手动刷新

## 安装

直接在[浏览器](https://tinker.liriliri.io/plugins/gold-price)中体验，或通过 [TINKER](https://tinker.liriliri.io/) 安装：

```bash
npm i -g tinker-gold-price
```

## 使用方法

1. 打开插件查看最新 Au9999 价格与分时图
2. 点击「刷新」重新加载行情与图表数据

## 数据来源

数据由 [East Money](https://www.eastmoney.com/) 行情提供。数据仅供参考，不构成投资建议。
