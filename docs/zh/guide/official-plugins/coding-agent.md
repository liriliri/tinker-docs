# tinker-coding-agent

[TINKER](https://github.com/liriliri/tinker) 的图形化编程助手插件，用于在本地工作区中查看和编辑代码。

![截图](https://raw.githubusercontent.com/liriliri/tinker-plugins/master/packages/tinker-coding-agent/screenshot.png)

## 功能特性

- **工作区对话**：探索并编辑本地项目文件夹
- **编码工具**：读取、写入、编辑文件，以及运行 shell 命令
- **模型选择**：使用已在 Tinker 中配置的 AI 提供商
- **Agent 技能**：通过 `/` 斜杠命令调用 `~/.agents/skills` 和项目技能
- **多会话**：侧边栏管理会话，并保留最近工作区
- **流式回复**：展示工具调用详情与上下文 token 用量
- **国际化**：支持中文和英文

## 安装

下载安装 [TINKER](https://tinker.liriliri.io/)，然后运行：

```bash
npm i -g tinker-coding-agent
```

## 使用方法

1. 点击 **Open Workspace** 选择项目文件夹
2. 选择已在 Tinker 中配置的 AI 提供商和模型
3. 让助手查看或编辑工作区中的代码
4. 在输入框中输入 `/` 浏览并插入技能
5. 使用侧边栏切换会话或打开最近工作区

## 示例提问

- `这个项目的整体结构是什么？总结主要文件夹和入口。`
- `这个应用是做什么的，面向谁？`
- `从高层次解释架构——主要模块以及它们如何协作。`
- `应用从哪里启动，启动时发生了什么？`
- `追踪主要用户操作的请求/响应流程。`
- `这个代码库如何管理状态？`
- `配置是在哪里加载的，哪些选项最重要？`
- `错误是如何处理并展示给用户的？`
- `关键的数据模型/类型有哪些，它们如何关联？`
- `数据如何从 UI 到存储（或 API）？`
- `这个项目依赖哪些外部服务或 API？`
- `找出理解核心逻辑最重要的文件，并简要说明每个文件。`
- `新贡献者应遵循哪些约定？`
- `给我一份简短的上手指南：先读什么、再读什么、然后读什么。`
