# tinker-game-music

[TINKER](https://github.com/liriliri/tinker) 的游戏 MIDI 音乐插件，支持按主机浏览、搜索、应用内试听，以及从 VGMusic 下载。

![截图](https://raw.githubusercontent.com/liriliri/tinker-plugins/master/packages/tinker-game-music/screenshot.png)

## 功能特性

- **按主机浏览**，覆盖主机与电脑平台
- **搜索**，可按曲名、游戏或作者筛选
- **MIDI 试听**，支持播放、拖动进度和停止
- **保存 MIDI** 到本地磁盘
- **随机播放**，在当前筛选列表中随机选曲

## 安装

下载安装 [TINKER](https://tinker.liriliri.io/)，然后运行：

```bash
npm i -g tinker-game-music
```

## 使用方法

1. 在左侧边栏选择一个主机
2. 展开游戏，点击曲目进行试听
3. 用搜索筛选曲目，或点击**随机**选一首
4. 点击**保存**下载当前 MIDI 文件

## 数据来源

MIDI 文件来自 [VGMusic.com](https://www.vgmusic.com/)。
