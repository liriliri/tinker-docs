# tinker-mouse-tester

[TINKER](https://github.com/liriliri/tinker) 的鼠标测试插件，实时可视化按键、滚轮与移动。

![截图](https://raw.githubusercontent.com/liriliri/tinker-plugins/master/packages/tinker-mouse-tester/screenshot.png)

## 功能特性

- **按键可视化**：支持左键、中键、右键和侧键（4 / 5）
- **滚轮反馈**：在鼠标示意图上显示上滚/下滚
- **实时遥测**：光标位置、移动增量与双击检测
- **光学感应区**：带传感器追踪指示的 UI
- **深色模式**：支持深色主题

## 安装

下载安装 [TINKER](https://tinker.liriliri.io/)，然后运行：

```bash
npm i -g tinker-mouse-tester
```

## 使用方法

1. 打开插件，在窗口内移动光标
2. 点击左键 / 中键 / 右键，在示意图上查看高亮
3. 使用侧键（后退 / 前进）和滚轮测试额外输入
4. 在右侧面板查看位置、增量、滚动方向和双击状态
