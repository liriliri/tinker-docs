# tinker-n64

适用于 [TINKER](https://github.com/liriliri/tinker) 的 N64 模拟器插件，支持 ROM 加载、键盘和手柄控制、存档以及全屏播放。

![截图](https://raw.githubusercontent.com/liriliri/tinker-plugins/master/packages/tinker-n64/screenshot.png)

## 功能特性

- **N64 模拟** — 基于 N64Wasm（Mupen64Plus）
- **ROM 加载** — 支持文件选择器、拖放，或点击空白画面加载（`.n64` / `.v64` / `.z64`）
- **重置** — 重新启动当前 ROM
- **保存 / 加载状态** — 保存或恢复游戏进度
- **静音 / 取消静音** — 切换音频开关
- **全屏** — 全屏模式播放
- **自定义按键映射** — 支持键盘和手柄，含摇杆轴映射
- **游戏历史** — 侧边栏浏览游玩记录，并支持 ROM 搜索

## 安装

下载并安装 [TINKER](https://tinker.liriliri.io/)，然后运行：

```bash
npm i -g tinker-n64
```

## 使用方法

1. 点击 **OPEN ROM** 加载 `.n64`、`.v64` 或 `.z64` 文件，将文件拖放到屏幕上，或点击空白画面
2. 使用键盘或手柄进行游戏
3. 点击 **RESET** 重新启动当前 ROM
4. 点击 **SAVE STATE** / **LOAD STATE** 保存或恢复进度
5. 点击 **MUTE** / **UNMUTE** 切换音频
6. 点击 **FULLSCREEN** 进入全屏模式
7. 点击 **KEY BINDINGS** 自定义键盘和手柄按键映射
8. 切换 **SIDEBAR** 浏览游戏历史，或在磁盘上搜索 ROM
