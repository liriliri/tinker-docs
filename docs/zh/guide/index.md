# 前言

TINKER 是一个集合了多款效率小应用的桌面工具箱。无论是快速计算、图片压缩还是绘制图表，TINKER 都提供了高质量的内置插件来高效完成日常任务。

## 为什么选择 TINKER？

在日常工作和生活中，我们常常需要各种小工具：计算器、取色器、图片压缩器等等。通常这些工具分散在不同的应用或网站中，需要频繁切换。TINKER 将多种实用工具整合到一个统一的应用中，解决了这个问题。

- **快捷呼出**：快捷键唤出，搜索工具回车即开，用完主窗口自动隐藏。
- **Agent 可用**：提供 CLI、MCP 与 Agent Skills，让 AI 直接打开和调用工具。
- **开箱即用**：内置大量高质量工具，覆盖编码、图片、文件、终端等日常场景。
- **本地优先**：工具在本地运行，数据不出本机，可自由导出备份，日常使用无需联网。
- **自由扩展**：支持安装官方、第三方、网页与游戏插件，一键扩充工具箱。

## 支持平台

TINKER 支持以下平台：

- Windows x64
- macOS Apple silicon
- macOS Intel chip
- Linux
