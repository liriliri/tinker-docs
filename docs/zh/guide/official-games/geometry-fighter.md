# tinker-geometry-fighter

在双摇杆几何射击中扛住越来越猛的敌潮。一款霓虹街机游戏，适用于 [TINKER](https://github.com/liriliri/tinker)。

![截图](https://raw.githubusercontent.com/liriliri/tinker-games/master/packages/tinker-geometry-fighter/screenshot.png)

## 特性

- **双摇杆战斗** — 一根摇杆移动，另一根瞄准开火
- **压力升级** — 存活越久敌潮越密，连杀会提高分数倍率
- **场上拾取** — 护盾、减速场、清屏炸弹，以及漂浮的武器与炸弹胶囊
- **霓虹网格** — 发光矢量战机、bloom，以及保存在本地的最高分

## 安装

直接在[浏览器](https://tinker.liriliri.io/games/geometry-fighter/)中体验，或通过 TINKER 安装：从 `https://tinker.liriliri.io/` 下载，然后运行 `npm i -g tinker-geometry-fighter`。

## 玩法

1. 在 TINKER 中打开**几何战机**插件
2. **点击**或按开火键开始
3. 用 **WASD** 或**左摇杆**移动。用**鼠标**或**右摇杆**瞄准——按住开火，或推动右摇杆即可射击
4. 用鼠标右键或右扳机引爆**炸弹**
5. 拾取漂浮胶囊可获得更宽的射击或额外炸弹。闪烁道具会给予护盾、减速所有敌人，或引爆全场
6. 按 **Escape** 或 **Start** 暂停。生命耗尽即游戏结束——再次开火即可重试
