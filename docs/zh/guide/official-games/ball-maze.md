# 滚球迷宫

滚动小球穿越程序生成的迷宫，找到出口！一款适用于 [TINKER](https://github.com/liriliri/tinker) 的 3D 物理益智游戏。

![截图](https://raw.githubusercontent.com/liriliri/tinker-games/master/packages/tinker-ball-maze/screenshot.png)

## 亮点

- **无限关卡** — 迷宫会随着你的进度越来越大，每次运行都会生成全新布局
- **逼真滚动** — Planck 物理引擎和旋转滚动的金属小球
- **沉浸式 3D 世界** — 石墙、地板纹理、动态光照和柔和阴影
- **实时小地图** — 在右上角追踪你的位置
- **满足感反馈** — 滚动和撞击墙壁的音效会根据速度和碰撞力度而变化
- **双语支持** — 完整支持英文和中文

## 安装

直接在[浏览器](https://tinker.liriliri.io/games/ball-maze/)中游玩，或通过 TINKER 安装：从 `https://tinker.liriliri.io/` 下载，然后运行 `npm i -g tinker-ball-maze`。

## 玩法

1. 在 TINKER 中打开**滚球迷宫**插件
2. 使用**方向键**或 **WASD** 推动小球穿越迷宫
3. 到达出口即可进入下一关 — 每一关都比上一关更大
4. 如果迷路了，可以查看**小地图**
5. 尽可能走得更远！
