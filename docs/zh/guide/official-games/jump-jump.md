# tinker-jump-jump

长按蓄力，松手起跳，落上下一个台子！一款适用于 [TINKER](https://github.com/liriliri/tinker) 的 3D 技巧游戏，灵感来自经典微信跳一跳。

![截图](https://raw.githubusercontent.com/liriliri/tinker-games/master/packages/tinker-jump-jump/screenshot.png)

## 特性

- **单指操作** — 长按蓄力，松手跳向下一个方块
- **完美落点** — 落在中心可获得连击加成与递增得分倍率
- **精致 3D 舞台** — 玻璃瓶角色、多样平台、柔和阴影与波纹特效
- **经典手感** — 基于时机的跳跃，配有蓄力、落地、连击与坠落音效
- **刷新纪录** — 最高分本地保存，方便持续挑战

## 安装

直接在[浏览器](https://tinker.liriliri.io/games/jump-jump/)中体验，或通过 TINKER 安装：从 `https://tinker.liriliri.io/` 下载，然后运行 `npm i -g tinker-jump-jump`。

## 玩法

1. 在 TINKER 中打开**跳一跳**插件
2. **按住**（鼠标、触屏或 Space）蓄力 — 按住越久，跳得越远
3. **松开**跳向下一个平台
4. 落在方块上得分；落在**中心**可触发完美连击
5. 未落上台子则游戏结束 — 点击 **Play Again** 再试一次
