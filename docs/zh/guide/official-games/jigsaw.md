# tinker-jigsaw

把碎片拖回原位，拼出整张图！一款适用于 [TINKER](https://github.com/liriliri/tinker) 的游行式拼图游戏。

![截图](https://raw.githubusercontent.com/liriliri/tinker-games/master/packages/tinker-jigsaw/screenshot.png)

## 特性

- **动态图库** — 数十张电影感国风画板，从武侠桥到云中寺庙
- **碎片游行** — 卡片沿边缘漂过；抓住每一块并拼回原位，别让它溜走
- **三种难度** — 每张图解锁简单、中等、困难网格，随图片本身缩放
- **自定义图片** — 从磁盘选择照片，做成新拼图
- **星星进度** — 每张图的通关进度会保存，方便持续冲榜

## 安装

直接在[浏览器](https://tinker.liriliri.io/games/jigsaw/)中体验，或通过 TINKER 安装：从 `https://tinker.liriliri.io/` 下载，然后运行 `npm i -g tinker-jigsaw`。

## 玩法

1. 在 TINKER 中打开**拼图**插件
2. 从图库中选择一张图，或点击空白格加载自己的图片
3. 从移动的游行中拖取碎片，放到棋盘上对应位置
4. 连续拼合可连击 — 错过的碎片会溜走
5. 拼完整张图后，再挑战下一星难度
