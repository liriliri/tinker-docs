# tinker-gomoku

一款精致的 3D 五子棋游戏，基于 Three.js 构建，适用于 [TINKER](https://github.com/liriliri/tinker)。

![截图](https://raw.githubusercontent.com/liriliri/tinker-games/master/packages/tinker-gomoku/screenshot.png)

## 特性

- **经典五子棋** — 标准 15×15 棋盘，带天元与星位，胜负连线动画清晰可见
- **多种玩法** — 本地双人对战，或挑战简单、普通、困难三种难度的电脑对手
- **多种操作** — 支持鼠标、触屏、键盘与手柄
- **沉浸式 3D 棋盘** — 圆角木质纹理、法线贴图、落子动画、光照与柔和阴影
- **记住选择** — 自动保存模式与难度设置
- **双语界面** — 支持英文与简体中文

## 安装

直接在[浏览器](https://tinker.liriliri.io/games/gomoku/)中体验，或通过 TINKER 安装：从 `https://tinker.liriliri.io/` 下载，然后运行 `npm i -g tinker-gomoku`。

## 玩法

1. 选择本地双人对战或人机对战，并选择难度。
2. 点击交叉点落子，或用方向键、WASD、手柄移动光标。
3. 按 **Space** 或 **Enter** 落子。黑方先行。
4. 按住**鼠标左键**拖动旋转棋盘，或用**鼠标右键**平移。
5. 先连成五子者获胜。
