# tinker-sudoku

在九宫格中填入 1–9，使每行、每列、每个宫格都不重复！一款经典的逻辑益智游戏，适用于 [TINKER](https://github.com/liriliri/tinker)。

![Screenshot](https://raw.githubusercontent.com/liriliri/tinker-games/master/packages/tinker-sudoku/screenshot.png)

## 亮点

- **四种难度** — 简单、中等、困难、疯狂，逐步减少已知数字的数量
- **智能提示** — 揭示缺失的数字，或在填满后修复错误
- **实用高亮** — 选中格子时高亮同行、同列、同宫和相同数字的格子
- **多种玩法** — 点击数字键盘、使用键盘（1–9 和方向键）或直接点击格子
- **内置计时器** — 记录每局用时
- **记住偏好** — 自动保存难度选择
- **双语** — 完整支持英文和中文（数独）

## 安装

直接在[浏览器](https://tinker.liriliri.io/games/sudoku/)中游玩，或通过 TINKER 安装：从 `https://tinker.liriliri.io/` 下载，然后运行 `npm i -g tinker-sudoku`。

## 玩法

1. 在 TINKER 中打开**数独**插件
2. 点击难度标签选择**简单**、**中等**、**困难**或**疯狂**
3. 点击空格子，然后从下方数字键盘选择一个数字（或按键盘上的 1–9）
4. 在每行、每列和每个 3×3 宫格中填入 1–9，不能重复
5. 使用**提示**获得帮助，**重置**清除已填数字，或**新游戏**开始新的一局
6. 填满所有格子即为胜利 — **谜题解决！**
