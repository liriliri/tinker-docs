# tinker-resume

A resume builder plugin for [TINKER](https://github.com/liriliri/tinker), with live preview, template selection, and PDF export.

![Screenshot](/resume.png)

## Features

- **Modular sections** — edit Profile, Skills, Experience, Projects, Education, Self evaluation, and Certificates; add or remove optional modules as needed
- **Live preview** — changes update the resume preview in real time
- **Templates** — switch between Classic (single column) and Sidebar layouts
- **Accent color** — customize the theme accent color from the toolbar
- **Item visibility** — hide or show individual experience, project, education, or certificate entries without deleting them
- **Section reorder** — drag sections in the sidebar to change their order on the resume
- **Photo support** — attach a profile photo from disk
- **Auto-save** — resume content, template, and accent color persist locally
- **PDF export** — export the current preview as a PDF file
- **AI assistant** — optional chat assistant to help write, edit, or translate the resume (when AI is available)

## Usage

1. Open a section from the left sidebar (e.g. Profile) and fill in your details
2. Add Experience, Projects, Education, or Certificates entries as needed
3. Use **Add module** at the bottom of the sidebar to restore any removed sections
4. Switch between **Classic** and **Sidebar** templates in the toolbar
5. Optionally adjust the **Accent** color
6. Click **Export PDF** to save the resume as a PDF
