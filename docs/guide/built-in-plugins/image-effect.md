# tinker-image-effect

A plugin for [TINKER](https://github.com/liriliri/tinker) to apply artistic effects to images, including sketch, pixel art, and ASCII art.

![Screenshot](/image_effect.png)

## Features

- **Sketch effect** — convert images into pencil sketches with adjustable thickness, brightness, detail, and deepen
- **Pixelate effect** — turn images into pixel art with configurable block size, optional black outlines, and 12 color palettes (PICO-8, Gameboy, Retro NES, Cyberpunk, and more)
- **ASCII effect** — render images as ASCII art with cell size, contrast, invert, and character sets (Simple, Detailed, Blocks)
- **Real-time preview** — adjust parameters with live preview updates
- **Drag & drop** — open images by drag and drop or file dialog (PNG, JPG, WebP, GIF, BMP)
- **Export** — save results as PNG, JPG, or WebP; optionally overwrite the original file
- **EXIF preservation** — preserves original EXIF metadata when saving JPEG files

## Usage

1. Click **Open Image** or drag and drop an image onto the canvas
2. Select an effect from the sidebar: **Sketch**, **Pixelate**, or **ASCII**
3. Adjust the effect parameters with the sliders and options
4. Preview the result in real time on the canvas
5. Click **Save Image** to export as PNG, JPG, or WebP
6. Enable **Overwrite** to save directly to the original file
