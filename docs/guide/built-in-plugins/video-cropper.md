# tinker-video-cropper

A video cropping plugin for [TINKER](https://github.com/liriliri/tinker), with interactive region selection and FFmpeg export.

![Screenshot](/video_cropper.png)

## Features

- **Interactive cropping** — drag and resize a crop region over the playing video
- **Aspect ratio presets** — Free, Original, 1:1, 4:3, 3:2, 16:9
- **Custom crop size** — set exact crop width and height in pixels
- **Drag and drop** — drop a video file onto the window to open it
- **Format support** — MP4, WebM, MOV, MKV, and more
- **FFmpeg export** — crop and save via FFmpeg, with progress feedback
- **Overwrite or save as** — save to a new file or overwrite the original

## Usage

1. Click the open area (or the toolbar open button) to load a video, or drag and drop a video file
2. Drag the crop box on the video to select the region to keep
3. Optionally choose an aspect ratio preset or set an exact crop size from the toolbar
4. Click **Crop** and choose where to save the result
5. When finished, the cropped video opens in the editor for further adjustments
