# tinker-reader

A PDF reader plugin for [TINKER](https://github.com/liriliri/tinker) with a built-in library to import and manage local books.

![Screenshot](/reader.png)

## Features

- **Library management** — import individual PDF files or scan folders to build your book collection
- **Gallery view** — browse books with auto-generated cover thumbnails, sorted by last opened time
- **Search** — filter books by title or file path
- **PDF reader** — read PDFs with page navigation, zoom in/out, and adaptive fit-to-width
- **Reading progress** — remembers last page and shows read percentage for each book
- **Sidebar** — toggle between thumbnail page previews and document outline for quick navigation
- **Read tracking** — tracks last opened time and reading progress per book

## Usage

1. Click **Import** to add individual PDF files, or **Scan Folder** to discover books in directories
2. Click a book card to open it in the reader
3. Use **Previous Page** / **Next Page** buttons or keyboard to flip pages
4. Use **Zoom In** / **Zoom Out** / **Reset Zoom** to adjust the view
5. Open the sidebar for page thumbnails or document outline navigation
6. Right-click a book in the gallery to remove it or show it in Finder
