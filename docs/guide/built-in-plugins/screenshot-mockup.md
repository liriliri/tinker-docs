# tinker-screenshot-mockup

A screenshot mockup plugin for [TINKER](https://github.com/liriliri/tinker) that beautifies screenshots with device frames and backgrounds for store or marketing visuals.

![Screenshot](/screenshot_mockup.png)

## Features

- **Device frames** — place screenshots in Phone, Tablet, or PC frames (or hide the frame)
- **Multi-device scenes** — add, duplicate, and remove multiple devices on one canvas
- **Canvas presets** — App Store, Play Store, Instagram, Open Graph, and custom sizes
- **Background options** — gradient presets, solid color, custom image, or transparent
- **Shadows & transforms** — drag, scale, rotate devices, and toggle drop shadows
- **Export** — export the composed mockup as an image

## Usage

1. Choose a canvas preset or set a custom size from the toolbar
2. Click a device to add a screenshot (or change an existing one)
3. Pick a device type (Phone / Tablet / PC) and toggle the device frame as needed
4. Style the background with a gradient, solid color, or image
5. Drag, scale, or rotate devices on the canvas; add more with the + button
6. Click Export to save the mockup
