# tinker-anniversary

A plugin for [TINKER](https://github.com/liriliri/tinker) to track annual anniversaries with calendar view and countdown.

![Screenshot](/anniversary.png)

## Features

- **Calendar view** — monthly calendar displaying all anniversary and holiday events
- **Solar and lunar calendar** — support both Gregorian (solar) and Chinese lunar calendar dates
- **Countdown sidebar** — sorted list of upcoming anniversaries and holidays with days remaining
- **Holiday display** — toggle to show public holidays on the calendar and sidebar
- **Start year tracking** — optionally set a start year to see days passed since the anniversary began
- **Lunar date labels** — in Chinese locale, each calendar cell shows the corresponding lunar date

## Usage

1. Double-click any date on the calendar to add a new anniversary
2. Enter a name and choose solar or lunar calendar, then set the date
3. Optionally set a start year to track how many days have passed
4. View upcoming anniversaries and holidays in the sidebar, sorted by days remaining
5. Click an item in the sidebar to navigate to that date on the calendar
6. Right-click an anniversary in the sidebar to edit or delete it
7. Use the checkbox in the toolbar to show or hide holidays
